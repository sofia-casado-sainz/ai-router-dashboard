# AI Router Dashboard

Sistema inteligente de enrutamiento de IA.

## Objetivos

- Selección automática de modelos
- Optimización de costes
- Auditoría de consumo
- Chat unificado multi-IA
- Métricas y analítica

## Stack

Frontend:
- Next.js
- Tailwind

Backend:
- FastAPI

Base de datos:
- PostgreSQL

IA:
- OpenRouter
- OpenAI
- Anthropic
- Gemini
